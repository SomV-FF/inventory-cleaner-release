# Inventory Cleaner

**Written using Astra and tested extensively in-game.**

A Dalamud plugin for organising FFXIV inventory, selling excess items, and updating retainer Marketboard listings.

## Install

1. Open `/xlsettings` and add this URL under **Experimental → Custom Plugin Repositories**:

   ```text
   https://raw.githubusercontent.com/SomV-FF/inventory-cleaner-release/main/repo.json
   ```

2. Open `/xlplugins`, search for **Inventory Cleaner**, and install it.
3. Open `/inventorycleaner`. At your home world's summoning bell, set up **Rules** and use **Cleanup** to review or run a plan.

If you already use the development copy, disable it before installing from the feed.
